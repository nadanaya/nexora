# 참가자 가정과 제약
공식: 관련자 2/3 일치, 월200만원 초과 임원 승인, 영업지원 절차, 기준일·통화·파일 형식.
추가 통제: 기안자와 승인자 분리, 지급 대상별 계좌 증빙 및 별도 검토, 문맥에 묶인 승인, 영업일 일정, 보류·정정 후 재심사, 모의 지급 멱등성. 공식 조항으로 오인하지 않는다.
구현 선택: NFC·앞뒤 공백의 보수적 정확 일치, 관계 정정일2026-07-01 고정, 테넌트 단위 JSONB 잠금. 대소문자·내부 공백·계좌 형식 통합은 미지원.
합성: API-/WEB- 거래처, 가상 역할, 소명 회신·검토·모의 지급. 제공 원본과 별도 DB에서 실행.
원본에 없는 사실: 당시 관계 이력·임원 승인서·검증된 지급 수취계좌·은행 결과. 미확인은 부정이나 승인 부재 확정이 아니다.
현금 가용액 한도를 임의로 추가하지 않았다. 실제 은행·외부 통지·현금절감 성과는 구현·측정하지 않았다.
AI 공급자·모델·비밀 키 없음. 실제 호출을 성공으로 표시하지 않는다. AI schema 오류/근거키 검증은 모의 응답 테스트다. 근거키 존재 검증이 모든 자연어 주장의 의미적 진실을 보장하지는 않는다.

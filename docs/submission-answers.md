## 1. 문제와 전문성 확장 요약

NEXORA는 Corevia 영업지원팀의 관련 거래처 판매장려금 심사를 영업임원 승인과 재무 모의 지급까지 연결합니다. 관련자 월 합계200만원 초과는 임원 승인 대상입니다. 관계 변경 영향 분석을 확장해 전후 그룹·금액·권한을 비교하고 승인 무효화·재무 일정 중지·대체 심사를 실행합니다. 영업팀의 증빙 소명과 재무팀의 승인 기반 일정 처리가 후속 업무입니다. 실제 절감액이나 개인 경력은 가정하지 않습니다.

## 2. 업무모델과 데이터 설명

거래처·관련 그룹·월 장려금·심사·증빙·승인·작업·일정·지급·감사를 연결합니다. 원본50거래처·240장려금·총232,865,386원을 검산했습니다. D-011·D-024·D-037의6월 합계는3,888,097원입니다. 직접 간선과 전이를 구분하며 입금계좌를 지급 수취계좌로 쓰지 않습니다. 공식 영업지원 절차와 한도를 유지하고 본인 승인 금지·증빙 검토·승인 문맥 검사를 추가했습니다. 원본·계산·가정·합성을 분리하고 당시 승인서 부재를 부정으로 단정하지 않습니다.

기존 브라우저 시연은 A200만원 지급·B240→90만원 분리·C보류와 거절입니다. 새 Guided Demo는 계정별 격리 DB에서 A120만원 지급, B계좌 정정으로120→230만원 합병 및 임원 재승인, C부족 정보 보류·영업 회신·거절을 제공합니다. 새 흐름을 실제 API·PostgreSQL 테스트로 검증했습니다. B의 Decision Replay에서 전후 그룹·금액·권한·상태를 비교하며 영업·재무·내부감시 작업을 생성합니다. AI 미연결 시 규칙 기반 설명으로 명시하고 실제 모델 호출과 구분합니다. 증거는 submission/evidence에 있습니다.

## 4. 추가 확장 목록

관계 변경 분석은 합병·분리·심사 대체·기지급 후속조사로 연결됩니다. 지급 멱등성·동시성은 중복 요청·취소 경합·원자성 테스트로 검증했습니다. AI는 스키마·근거키·금액 실행 필드 삽입을 검증하며 오류가 업무 규칙을 바꾸지 않습니다. AI 오류 검사는 모의 응답이며 실제 모델 성과가 아닙니다. 임의 과거·미래 그래프와 실제 은행 연동은 미구현입니다.

# AI 실호출에 필요한 설정

2026-11-10 확인 결과, 로컬에는 관계 비교용 비밀 설정만 있고 운영 앱에는 관계 비교·기존 등록용 비밀 설정만 있습니다. AI 키·모델·제공자 주소는 없으며 lounge의 테넌트 AI 제공자는 비활성 상태입니다. 다른 로그인 토큰이나 기록 키를 모델 API 키로 전용하지 않았습니다.

서버에 다음 세 가지를 설정해야 합니다.

- `LLM_API_KEY`: 사용 권한을 가진 모델 공급자의 API 키. 서버 비밀 설정으로 등록합니다.
- `LLM_BASE_URL`: 해당 공급자의 OpenAI 호환 Chat Completions 기본 HTTPS 주소. 코드가 `/chat/completions`를 덧붙이므로 `/v1`까지의 기본 주소를 사용합니다.
- `LLM_MODEL`: 그 계정에서 실제 사용할 수 있는 모델 식별자. 특정 모델의 사용 가능 여부를 추정하지 않습니다.

키는 채팅·소스·화면·로그에 넣지 않습니다. `NEXT_PUBLIC_` 이름을 사용하지 않습니다. 현재 `.env.local`에 있는 관계 비교용 키는 덮어쓰거나 회전시키지 않습니다. 운영 값은 AXHub 환경변수 비밀 등록으로 전달하고 재배포해야 합니다.

설정 후 `GET /api/v1/analysis/configuration`의 configured 값을 확인하되, 이것은 값의 존재만 뜻합니다. 실제 성공은 `test_actual_external_model_call`과 심사의 AI 버튼으로 모델 응답을 받은 뒤 판단해야 합니다. 테스트 프로세스에도 세 환경변수를 전달해야 합니다. 로컬 파일만 작성하고 Python 환경에 전달하지 않으면 외부 모델 테스트는 건너뜁니다.

입력은 직접 관계 간선·장려금 행 참조·서버 계산·차단 사유·검토된 증빙 구분입니다. 대표자·주소·전체 계좌·예금주 원문은 모델에 보내지 않습니다. 출력은 summary, relationship_evidence, payment_risks, missing_evidence, suggested_tasks, facts, uncertainties, suggested_actions, limitations이며, authoritative rule_result는 모델이 아닌 서버가 첨부합니다.

모델의 출력에 금액·승인 실행 필드를 삽입하면 거부합니다. 모델에는 상태 변경 도구가 없으며, 실제 근거 키만 참조할 수 있습니다. 오류·타임아웃·형식 오류·허위 근거는 실패 감사 이벤트를 남기고 사람 승인·지급 상태를 유지합니다. 정보 변경 전 분석은 오래된 분석으로 표시합니다.

현재 제출 시 A 시나리오는 “AI 미설정 차단을 확인한 업무 시연”으로 설명해야 합니다. 모의 모델 테스트 통과를 “외부 AI 실호출 성공”으로 표현하면 안 됩니다.

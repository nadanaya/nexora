# NEXORA · W07

NEXORA는 Corevia 판매장려금 업무의 거래처 관계 분석, 월별 한도 검토, 사람 승인, 소명, 모의 지급과 감사 이력을 연결하는 AXHub 앱입니다.

## 실행

Node.js 20.19 이상을 사용합니다.

```powershell
npm ci
npm run dev
```

PostgreSQL 연결은 배포 환경에서 AXHub가 제공합니다. 로컬에서 API까지 실행하려면 `.env.local`에 `DATABASE_URL`을 설정하고 `npm run db:up`으로 개발용 DB를 띄운 뒤, 앱 관리자 계정으로 접속합니다.

## 업무 흐름

1. 앱 관리자가 거래처 마스터, 판매장려금, 입금 이력 CSV를 한 번 등록합니다. 파이프(`|`) 구분 형식이며 세 파일을 함께 선택해야 합니다.
2. 대표자·주소·등록 계좌·입금 계좌 중 두 가지 이상이 일치하는 거래처를 직접 연결하고, 연결을 전이적으로 묶습니다.
3. 관련 거래처 그룹의 월 장려금을 합산합니다. 2,000,000원 이하는 영업지원팀, 초과는 영업임원 권한이 필요합니다.
4. 승인·반려·소명 요청과 회신을 기록하고, 관련 그룹의 미지급 건이 모두 승인된 뒤에만 모의 지급을 기록합니다.

## 자료와 접근

- 업로드된 원본 파일 자체는 보관하지 않습니다. 관계 계산 후 거래처 이름, 장려금 처리 정보, 일치한 근거 필드와 계좌 끝 4자리만 저장합니다. 전체 주소·대표자명·계좌번호는 저장하지 않습니다.
- 실제 입금 계좌는 관계 분석 신호로만 사용합니다. 지급 수취계좌 필드는 없으며 은행 이체는 실행하지 않습니다.
- 자료는 AXHub 로그인 사용자 중 NEXORA에 등록된 역할이 있는 사람만 볼 수 있습니다. 앱 관리자는 사용자 ID를 영업지원팀·영업임원·조회전용으로 지정합니다.
- 관계 일치는 검토 신호이며 부정행위의 증거가 아닙니다. 승인과 지급 전 사람의 검토가 필요합니다.
- 공개된 앱에 실제 CSV를 업로드하기 전에 조직의 데이터 공유 승인을 확인하세요.
